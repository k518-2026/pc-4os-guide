# Wi-Fiが遅い・突然切れる原因の切り分けと改善チェック実例｜Windows・macOS・iOS・Android

「動画を見ようとしたら急に止まる」「Webサイトの読み込みが異常に遅い」「Wi-Fiがつながっているはずなのにネットに繋がらない」……。こうしたネットワークトラブルは、仕事やプライベートの時間を阻害する大きなストレスです。

原因は「ルーターの不調」「周囲の電波干渉」「端末固有の設定」「ISP（プロバイダー）の制限」など多岐にわたります。この記事では、Windows、macOS、iOS、Androidの4つの主要OSにおいて、**標準機能だけでできるトラブルシューティングと設定の見直し手順**を徹底解説します。

まずは基本の切り分けフローを確認し、ご自身の環境に合わせた対策を実践してみましょう。

## 4OS比較早見表

| 機能・項目 | Windows 11 | macOS | iOS (iPhone/iPad) | Android |
| :--- | :--- | :--- | :--- | :--- |
| **DNS手動設定** | 設定画面から可能 | システム設定から可能 | Wi-Fi詳細設定から可能 | 設定のネットワーク詳細から可能 |
| **周波数帯固定** | ドライバ依存（UIでは不可） | 非対応（ルーター側で制御） | 非対応（ルーター側で制御） | 非対応（ルーター側で制御） |
| **SMB共有接続** | 標準機能で対応 | Finderから対応 | 「ファイル」アプリで対応 | Files by Google等で対応 |
| **自動診断ツール** | あり（ネットワーク診断） | なし（手動確認が主） | なし（再起動・リセットが主） | あり（ネットワーク診断） |

## 1. Windows 11 での実例手順

Windowsは高度なネットワーク管理が可能ですが、その分設定項目も多く、ドライバの状態に左右されることもあります。

### 標準機能に基づく実例手順
*   **接続問題の自動修復**: 「設定」>「ネットワークとインターネット」>「ステータス（またはネットワークの詳細）」より「ネットワークの問題のトラブルシューティング」を実行します。これはMicrosoft公式の診断ツールで、IPの競合やDNSの不備を自動で検知します。
*   **DNSの変更**: 「設定」>「ネットワークとインターネット」>「Wi-Fi（またはイーサネット）」>「プロパティ」を開きます。「IP割り当て」の「編集」をクリックし、「手動」を選択。IPv4をオンにし、DNSサーバーアドレスに `8.8.8.8` (Google) や `1.1.1.1` (Cloudflare) を入力します。
*   **Wi-Fi アダプターの省電力オフ**: 「デバイスマネージャー」>「ネットワークアダプタ」>「無線LANデバイス（Intel/Realtek等）」を右クリック >「プロパティ」。**「電源の管理」タブ**がある場合、「コンピューターがこのデバイスの電源をオフにできるようにする」のチェックを外します。
*   **ファイル共有による負荷確認**: 「設定」>「ネットワークとインターネット」>「ネットワークの詳細設定」から、不要なSMB共有や古いプロトコルの利用状況を確認し、不要なフォルダの共有を無効化します。

### 標準機能の制限事項・注意点
*   **周波数帯の自動切り替え**: Windowsの標準GUI上では、2.4GHzと5GHzの強制固定は行えません。これはドライバまたはルーター側の設定（SSIDの分離など）で制御する必要があります。
*   **Wi-Fi 6E/7 の完全利用**: 最新規格をフル活用するには、OSのアップデートだけでなく、ネットワークアダプタのドライバが最新であること、およびハードウェア自体が対応していることが必須条件です。

### よくあるトラブルと解決法
1.  **「インターネットなし」エラーが頻発する**
    *   **原因**: DNS解析の失敗やルーターへの再接続拒否。
    *   **対策**: 「ネットワークの問題のトラブルシューティング」を実行し、DNSを手動で `8.8.8.8` 等に変更して再試行してください。
2.  **「Wi-Fi が突然切断される」**
    *   **原因**: 省電力設定によるアダプタのシャットダウン。
    *   **対策**: デバイスマネージャーから該当ドライバの「電源管理」タブを確認し、省電力機能をオフにします。
3.  **「Wi-Fi 6E ルーターだが速度が出ない」**
    *   **原因**: ドライバが2.4GHz帯にフォールバックしている。
    *   **対策**: メーカー公式サイトから最新ドライバをインストールし、アダプタのプロパティで高速モードが有効か確認してください。

## 2. macOS での実例手順

macOSは安定性が高い一方で、ネットワークの詳細設定は「システム設定」の深い階層に隠れていることが多いです。

### 標準機能に基づく実例手順
*   **DNSの変更**: 「システム設定」>「ネットワーク」>「Wi-Fi」を選択し、「詳細...」ボタンをクリック。「TCP/IP」タブを開き、「DNSサーバー」の項目で「＋」ボタンを押し、任意のDNS（`1.1.1.1`など）を入力します。
*   **ファイル共有による負荷確認**: 「システム設定」>「一般」>「共有」からSMBファイル共有の状態を確認します。不要な共有がオンになっているとネットワーク帯域を圧迫することがあります。
*   **Wi-Fi の周波数帯固定**: macOSのシステム画面内では2.4GHz/5GHzの強制固定は非対応です。ルーター側でSSIDを分けるか、ルーターの設定で制御する必要があります。

### 標準機能の制限事項・注意点
*   **DNSの自動取得優先**: 「使用 DNS サーバー」を空欄にするとISPから自動割り当てされます。手動入力時に「接続できない」と表示される場合は、一度デフォルトに戻してから再設定を試みてください。
*   **「ファイル」アプリからの直接アクセス制限**: FinderからSMBサーバーへ接続する際、ユーザー名・パスワードの正確な入力が必要です。認証プロトコルの不一致がある場合、標準機能のみでは解決できないことがあります。

### よくあるトラブルと解決法
1.  **「インターネットなし」表示だがブラウザが使える**
    *   **原因**: DNSのみ不通（キャッシュやプロキシ設定の誤り）。
    *   **対策**: 「システム設定」>「ネットワーク」でDNSを再入力し、ルーターを再起動後に再接続してください。
2.  **「Wi-Fi が突然切断される」**
    *   **原因**: 省電力機能によるスリープまたは干渉。
    *   **対策**: 「システム情報」からワイヤレスカードのモデルを確認し、Appleサポートページで最新のファームウェア/OSアップデートがないか確認してください。
3.  **「SMB ファイル共有が接続できない」**
    *   **原因**: Windowsサーバー側のSMBv1無効化や認証プロトコルの不一致。
    *   **対策**: 接続先（Windows側）でSMBプロトコルバージョンを確認し、macOS側で正しいユーザー情報を入力して再構成してください。

## 3. iOS（iPhone / iPad）での実例手順

モバイル端末では「省電力」と「移動による切断」が主な要因となります。

### 標準機能に基づく実例手順
*   **DNSの変更**: 「設定」>「Wi-Fi」>該当ネットワーク名の横の「i」マークをタップ。「DNS」を選択し、「手動」に切り替えてIPアドレスを入力します。
*   **「ファイル」アプリからサーバへ接続**: 標準の「ファイル」アプリを開き、サイドバーの「…」ボタン（または場所を追加）から、SMBサーバーのIPアドレスとユーザー情報を入力して接続します。

### 標準機能の制限事項・注意点
*   **DNS の変更方法**: iOSでは静的IPの設定などは非対応であり、DNSの変更のみが主なカスタマイズ項目です。
*   **「ファイル」アプリの接続条件**: サーバー側の共有フォルダにアクセスするには適切な認証が必要です。標準機能では高度な暗号化プロトコルの選定ができないため、サーバー側でNTLMv2などの対応を有効にする必要があります。

### よくあるトラブルと解決法
1.  **「Wi-Fi が突然切断される」**
    *   **原因**: 省電力設定やルーターの接続制限（MACアドレスフィルタリング）。
    *   **対策**: 「設定」>「一般」で最新OSに更新。また、一度ネットワークを削除し、パスワードを再入力してセッションを確立し直してください。
2.  **「ファイルアプリがサーバーに接続できない」**
    *   **原因**: サーバー側のSMB認証エラーまたはDNS不通。
    *   **対策**: 「設定」でDNSを変更し、「ファイル」アプリ内でユーザー名とパスワードを再入力して試行してください。
3.  **「Wi-Fi に接続できるが速度が遅い」**
    *   **原因**: 2.4GHzバンドでの干渉または帯域制限。
    *   **対策**: ルーター側でiOSデバイスを5GHz/6GHzベースバンドに固定するか、iPhoneのWi-Fi設定から一度オフにして再接続してください。

## 4. Android での実例手順

Androidはメーカー（Pixel, Galaxy等）によってUIが異なりますが、基本構造は共通しています。

### 標準機能に基づく実例手順
*   **DNSの変更**: 「設定」>「ネットワークとインターネット」>「インターネット（またはWi-Fi）」>該当ネットワークの歯車アイコン >「詳細設定（または編集）」から、プライベートDNSまたはDNSサーバーを手動入力します。
*   **「ファイル」アプリからのサーバー接続**: Google公式の「Files by Google」や端末標準の「マイファイル」等から、SMBプロトコルを使用して共有フォルダへアクセスします。

### 標準機能の制限事項・注意点
*   **周波数帯の固定不可**: Androidのシステム設定画面内では2.4GHzと5GHzの強制切り替えは非対応です。ルーター側での制御が必要です。
*   **「ファイル」アプリの実装差**: メーカー固有のファイルマネージャーにより、SMB接続時のプロトコルバージョン選択画面の有無に差異があります。

### よくあるトラブルと解決法
1.  **「Wi-Fi が突然切断される」**
    *   **原因**: 省電力設定によるスリープまたはドライバの不安定化。
    *   **対策**: 「設定」>「バッテリー & デバイスケア」からWi-Fiの最適化をオフにし、システムアップデートを確認してください。
2.  **「ファイルアプリがサーバーに接続できない」**
    *   **原因**: サーバー側のSMBv1無効化または認証エラー。
    *   **対策**: 「設定」>「Wi-Fi」でDNSを確認し、正しいユーザー情報を入力して再試行してください。

## よくあるトラブルと解決チェックリスト

| 現象 | チェック項目 | 推奨されるアクション |
| :--- | :--- | :--- |
| **速度が極端に遅い** | 周波数帯の確認 | 2.4GHz（干渉多）ではなく5GHz/6GHzを優先的に使用する。 |
| **頻繁に切断される** | 省電力設定の確認 | PC・スマホ共に「Wi-Fi省電力モード」や「スリープ時の接続維持」を確認。 |
| **特定のサイトだけ開けない** | DNSの不備 | Google DNS (8.8.8.8) や Cloudflare (1.1.1.1) へ変更してみる。 |
| **サーバーに繋がらない** | SMBプロトコル | サーバー側のSMBv1が無効化されていないか、認証情報が正しいか確認。 |

## まとめ：快適なマルチOS環境を作るポイント

Wi-Fiのトラブルは、端末の設定を見直すことで解決することも多いですが、根本的な解決には「インフラ（ハードウェア）」の見直しも非常に重要です。

特に複数のデバイス（Windows, Mac, iPhone, Android）を同時に利用する場合、以下の導入を検討することで劇的に安定性が向上します。

*   **Wi-Fi 6/6E/7ルーター**: 最新規格のルーターは、多数のデバイスが同時接続しても帯域を効率よく分配し、遅延を最小限に抑えます。
*   **家庭用NAS**: ファイル共有の負荷を端末から切り離し、安定したデータアクセス環境を構築できます。
*   **LANケーブル & スイッチングハブ**: 可能な限りデスクトップPCやサーバーは有線接続に。高品質なLANケーブルとスイッチングハブを導入することで、Wi-Fiの干渉に左右されない「鉄板」の通信環境が手に入ります。

まずは今回紹介したOSごとの設定チェックを行い、それでも改善しない場合はルーターやネットワーク機器のアップグレードを検討してみてください。
