# 2つの文章・原稿の違いを一瞬で見抜く「差分比較（Diff）」の実例｜Windows・macOS・iOS・Android

「この修正、どこが変わったんだっけ？」「前回の原稿と何が違うのか、目視では限界がある……」

プログラミングのコード修正から、重要な契約書の微調整、あるいはブログ記事の推敲まで、**「2つのテキストの差分（Diff）」を正確に把握する作業**は、あらゆる仕事において避けて通れない工程です。特に複数のデバイスを使い分けている場合、OSごとに最適な比較方法を知っておくことは、ミスを防ぎ生産性を高めるための必須スキルと言えます。

この記事では、特別なツールをインストールすることなく、ブラウザとGitHubのインフラを活用して**Windows、macOS、iOS、Androidの全環境で「差分比較」を実現する実践的な手順**を徹底解説します。

## 4OS比較早見表

| OS | 推奨アプローチ | 特徴・メリット | 標準機能での制限 |
| :--- | :--- | :--- | :--- |
| **Windows 11** | ブラウザ + github.dev | 高い操作性と正確なハイライト表示 | ローカルファイルの直接比較不可 |
| **macOS** | ブラウザ + github.dev | 洗練されたUIでスムーズな比較 | Finderに標準の比較コマンドなし |
| **iOS** | GitHub Mobileアプリ | 外出先でも手軽に確認可能 | 画面サイズによる視認性の制約 |
| **Android** | GitHub Mobileアプリ | 機種を問わず安定した操作感 | 標準メモ帳等でのDiff機能なし |

## 1. Windows 11 での実例手順

Windows環境では、ブラウザベースの「GitHub Dev」を活用することで、高度なDiffビューアを無料で利用できます。

### 実例手順：公式 GitHub Dev を使う
1. **準備**: Edge や Chrome で [github.dev](https://github.dev) にアクセスし、GitHubアカウントでログインします。
2. **リポジトリ作成/選択**: 「New Repository」から空のリポジトリを作成（または既存のものを開く）します。
3. **ファイルアップロード・比較**:
   - 左側の「Files」タブに `original.txt` と `modified.txt` の2つをドラッグ＆ドロップして追加。
   - ファイル名をクリックし、右クリックメニューから**「Compare with other files...」**を選択。
   - **Diff Viewer**で変更箇所（赤：削除・青：追加）がハイライト表示されます。
4. **保存**: 画面右上のボタンやCommitフローに従い、変更を永続化します。

### 標準機能の制限事項
*   **ローカルファイル直接読み込み不可**: `github.dev` はWebベースのため、Cドライブ等のローカルファイルを「Ctrl+O」で開いて比較する機能は**非対応**です。必ずGitHubにアップロードしたリポジトリ内のファイルを対象とします。
*   **Word文書 (.docx) の直接差分表示不可**: `.txt` やコード形式のみが正確にDiff可能です。.docxファイルは「文字化け」または「比較不能」となるため、純粋なテキスト抽出が必要です。

### よくあるトラブルと解決法
1. **エラー: "Authentication failed" / ログインできない**
   - **原因**: GitHubの認証トークン期限切れやブラウザキャッシュの問題。
   - **解決**: ブラウザを再起動し「Sign out」から再度ログイン。必要に応じてDeveloper Settingsで新しいトークンを発行してください。
2. **「Compare with other files...」メニューが表示されない**
   - **原因**: ファイルがリポジトリに存在しない、またはGitのインデックス化されていない。
   - **解決**: 「Files」タブで両方のファイルを確実にアップロードし、「Commit changes」を完了させてから再度メニューを開いてください。
3. **日本語の全角文字が比較時に崩れる**
   - **原因**: エンコーディング設定やブラウザの表示問題。
   - **解決**: ファイルをアップロードする際、UTF-8形式であることを確認してください。ローカルWordからのコピペではなく、テキストエディタ経由での貼り付けを推奨します。

## 2. macOS での実例手順

macOSユーザーもWindowsと同様に `github.dev` を活用するのが最も確実ですが、Finderの操作感の違いに注意が必要です。

### 実例手順：公式 GitHub Dev を使う
1. **準備**: Safari または Chrome で [github.dev](https://github.dev) にアクセスし、ログインします。
2. **リポジトリ操作**: 「New Repository」から空のリポジトリを作成。
3. **ファイルアップロード・比較**:
   - Finderからテキストファイルをドラッグ＆ドロップして追加（Web経由のみ）。
   - ファイル名をクリックし、「Compare with other files...」を選択してDiffを確認します。

### 標準機能の制限事項
*   **Finderの「比較」コマンド**: macOS Finderには「ファイル > 比較」という直接的な差分表示コマンドは**存在しません**。純正アプリでのテキスト並列比較は標準機能では不可能です。
*   **TextEditの制限**: テキストエディタ（.txt）の保存時に「リッチテキスト」ではなく「プレーンテキスト (.txt)」を選択しないと、Diffツールが誤作動する可能性があるため注意が必要です。

### よくあるトラブルと解決法
1. **「Save changes to GitHub.com」ボタンが表示されない**
   - **原因**: 変更内容がない場合や、ブラウザのJavaScriptエラー。
   - **解決**: ファイルを編集して少なくとも1つの変更（スペースを入れる等）を行い、「Commit message」を入力してから保存ボタンを確認してください。
2. **Safariで画面がフリーズする**
   - **原因**: Safariのキャッシュや拡張機能が github.dev と競合。
   - **解決**: 「設定 > プライバシーとセキュリティ > すべてクリア」で履歴を消去するか、Chrome/Firefoxに切り替えて試してください。
3. **ファイルアップロード時に「Too large」と表示される**
   - **原因**: リポジトリサイズ制限や一度に大量のファイルをアップロード。
   - **解決**: 大規模な文書比較は避け、小ファイルに分割して扱うことを推奨します。

## 3. iOS（iPhone / iPad）での実例手順

モバイル環境ではブラウザよりも公式アプリを組み合わせることで、安定した操作感を得られます。

### 実例手順：ブラウザと公式アプリ「GitHub Mobile」の連携
1. **準備**: Safariで [github.dev](https://github.dev) にアクセスするか、App Storeの「GitHub」アプリをインストールします。
2. **ファイルアップロード・比較**:
   - iPadOS/iPhone OSではドラッグ＆ドロップが制限されるため、「Share Sheet（共有メニュー）」からテキストファイルをリポジトリに追加します。
   - 画面下部の「Files」タブで両方のファイルを選択し、Diffを確認します。

### 標準機能の制限事項
*   **キーボード操作の限界**: iOSのSafariでは「Ctrl+O」（開くコマンド）は**存在しません**。必ず「共有」メニューからファイルを選択する必要があります。
*   **マルチタッチでの複雑な操作不可**: 2つ以上のファイルを同時に選択して比較するUIが簡略化されており、ボタンが非表示になることがあります。GitHub Mobileアプリの方が安定します。

### よくあるトラブルと解決法
1. **「共有」メニューからファイル追加ができない**
   - **原因**: ファイル形式がGitHubの受付外（画像など）か、アプリの権限不足。
   - **解決**: テキスト比較は `.txt` に限定。テキストをコピーして貼り付ける方法でファイルを作成し、共有メニューから追加してください。
2. **画面が狭すぎてDiffが見にくい**
   - **原因**: iPhoneの小画面では左右並列表示が困難。
   - **解決**: iPadOSなら「Split View（分割表示）」を使い、ブラウザとGitHubアプリを同時に開くのが有効です。
3. **「Commit changes」ボタンが表示されない**
   - **原因**: iOS Safariでのタッチ操作によるバグ。
   - **解決**: GitHub Mobileアプリをインストールし、アプリ内でリポジトリを開いて比較するのが最も確実です。

## 4. Android での実例手順

Androidでは機種ごとのカスタマイズ性が高いため、公式アプリの活用が最も汎用的な解決策となります。

### 実例手順：ブラウザと公式アプリ「GitHub Mobile」の活用
1. **準備**: ChromeやEdgeで [github.dev](https://github.dev) にアクセスするか、Google Playの「GitHub」アプリをインストールします。
2. **ファイルアップロード・比較**:
   - 「Share Sheet（共有メニュー）」からテキストファイルをリポジトリに追加。
   - アプリ内またはブラウザ内で両方のファイルを選択し、Diffを確認します。

### 標準機能の制限事項
*   **機種による名称差**: 設定やアプリ名はメーカー（Samsung / Google Pixel等）により異なりますが、「GitHub Mobile」自体の操作は統一されています。
*   **標準機能での差分表示不可**: Android純正の「テキストエディタ」や「メモ帳」にはDiff比較機能は**存在しません**。必ずGitHubのWebサービスまたは公式アプリを利用する必要があります。

### よくあるトラブルと解決法
1. **「共有」メニューからファイル追加ができない（Samsung Galaxyなど）**
   - **原因**: カスタムUIによるブラウザのShare Sheetとサードパーティ製ファイルマネージャーの連携制限。
   - **解決**: 「Files by Google」などでファイルを準備し、「GitHubアプリ」内の「Import file」機能を使って直接アップロードしてください。
2. **画面解像度による表示崩れ**
   - **原因**: 一部のAndroidモデルでのWebブラウザのフォント・レイアウト最適化不足。
   - **解決**: ブラウザの「デスクトップ用サイトを表示」をオンにするか、GitHub Mobileアプリに切り替えて操作してください。

## よくあるトラブルと解決チェックリスト

*   **[ ] 比較結果が正しく表示されない（ハイライトが出ない）**
    *   原因：ファイルがプレーンテキスト（.txt）ではなくリッチテキスト形式になっている可能性があります。
    *   対処：メモ帳やVS Code等で「プレーンテキスト」として保存し直してからアップロードしてください。
*   **[ ] ログインエラーが繰り返される**
    *   原因：ブラウザのキャッシュまたはGitHub側の認証セッション切れ。
    *   対処：シークレットモード（インコグニートモード）でアクセスを試し、解決すればキャッシュをクリアしてください。
*   **[ ] ファイルのアップロード自体に失敗する**
    *   原因：ファイルサイズが大きすぎるか、ネットワークが不安定。
    *   対処：ファイルを分割するか、安定したWi-Fi環境下で再試行してください。

## まとめ：快適なマルチOS環境を作るポイント

今回ご紹介した「GitHub Dev」を活用した手法は、OSを問わず正確な差分比較を行うための最も強力な標準的アプローチです。しかし、より高度な作業効率を求めるなら、以下の周辺機器やツールの導入も検討の価値があります。

*   **メカニカルキーボード**: 長時間のテキスト編集やコード修正において、正確な打鍵感はミスを減らし、集中力を維持する大きな助けとなります。
*   **ウルトラワイドモニター**: 左右に2つのファイルを並べて比較する際、広い作業スペースは「Diff」の視認性を劇的に向上させます。
*   **技術書（電子書籍）**: OSごとの操作やGitHubの高度な活用術を網羅した技術書を常備することで、トラブル発生時の自己解決能力が高まります。
*   **VPS・クラウド環境**: 常に最新の比較ツールや開発環境をクラウド上に構築しておくことで、どのデバイスからでも「同じ作業環境」にアクセスでき、マルチOSでの生産性が最大化されます。

正しいツールと環境を整えることで、あなたの「差分チェック」はストレスから解放され、よりクリエイティブな作業に集中できるものになるはずです。
