# 【4OS徹底比較】PDFの結合・分割・圧縮を無料で行う実例ガイド｜Windows・macOS・Linux・iPad

「仕事で送られてきた複数のPDFを1つにまとめたい」「長い資料の一部だけを抽出したい」「メールで送るためにファイルサイズを小さくしたい」……。こうした場面で、有料のAdobe Acrobatなどの高機能ソフトを契約するのは少しハードルが高いと感じる方も多いはずです。

実は、**私たちが普段使っているOS（Windows, macOS, Linux, iPadOS）には、標準機能や基本的なツールだけでこれらの操作を行う方法が備わっています。** 

この記事では、プロの視点から4つの主要なOSにおける「PDFの結合・分割・圧縮」の手順を徹底比較します。外部アプリを極力使わず、標準機能を使いこなすための実践的なガイドとして活用してください。

## 4OS比較早見表

| OS | 主な操作手段 | 結合 | 分割 | 圧縮 | 特徴 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Windows** | Microsoft Print to PDF | △（印刷利用） | △（範囲指定） | △（DPI変更） | ブラウザや仮想プリンタを活用するスタイル |
| **macOS** | プレビュー (Preview) | ◎（ドラッグ＆ドロップ） | ◎（ページ削除） | △（再出力） | 直感的で最も標準機能が充実している |
| **Linux** | CLI (`pdftk`, `pdfunite`) | ◎（コマンド） | ◎（コマンド） | △（linearize） | 確実な処理が可能だが、基本はターミナル操作 |
| **iPadOS** | ファイル / ショートカット | △（ショートカット活用） | △（ページ削除） | ×（標準では困難） | モバイル特有の制約があり、自動化が必要 |

## 1. Windows での実例手順

Windows環境では、専用のPDF編集ソフトをインストールせずに「仮想プリンタ」としての機能を利用するのが最も標準的なアプローチです。

### 具体的な実例手順
*   **結合**: 複数のPDFを開き、「印刷」メニューから「Microsoft Print to PDF」を選択します。ただし、これは「並べて表示して印刷する」というアナログな手法に近いものになります。
*   **分割**: EdgeブラウザでPDFを開き、印刷ダイアログ（Ctrl + P）を表示します。出力先を「Microsoft Print to PDF」にし、「ページ」の欄に抽出したい範囲（例：`1-3, 5`）を入力して実行することで、指定したページだけの新規PDFとして保存できます。
*   **圧縮**: Windows標準ではボタン一つで圧縮する機能はありません。印刷ダイアログの「プロパティ」から解像度を調整します。
    *   **手順**: [Microsoft Print to PDF] のプロパティ > 詳細設定 > 解像度を「72 dpi」などに下げる（※画質劣化に注意）。

### よくあるトラブルと解決チェックリスト
1.  **結合後の文字が崩れる・レイアウトがおかしくなる**
    *   原因：PDFに埋め込まれたフォントが含まれていない、または印刷時の解像度不足。
    *   解決策：Edgeの印刷設定で「システムダイアログを使用する」を試し、高品質なグラフィックス出力を確認してください。
2.  **分割時にページ番号がずれる**
    *   原因：プレビュー表示での範囲選択ミス。
    *   解決策：「ファイル > ページのプレビュー」で正確な範囲（例：1-3, 5-7）を青く塗りつぶし、印刷ダイアログで再確認してください。
3.  **圧縮してもサイズが減少しない**
    *   原因：Windows標準機能では画像のJPEG品質制御ができないため。
    *   解決策：解像度（dpi）を下げる以外に標準機能での大幅な軽量化は困難です。

## 2. macOS での実例手順

macOSは「プレビュー」アプリの性能が高いため、最もスムーズに操作が行えます。

### 具体的な実例手順
*   **結合**: 「プレビュー」で複数のPDFを開きます。サイドバー（表示 > サイドバー）を表示し、サムネイルパネルから必要なページを選択して、別のPDFウィンドウへドラッグ＆ドロップします。最後に「ファイル > エクスポート PDF...」で保存します。
*   **分割**: 1つのPDF内で不要なページを削除する方法が最も簡単です。「編集」メニューの「ページを削除」またはサムネイルを右クリックして削除を選択します。残ったページを新規保存することで分割が完了します。
*   **圧縮**: 「印刷」ダイアログから「PDFとして保存」を選択します。標準機能のみでは高度な最適化はできませんが、再出力時に解像度を指定することで簡易的なサイズ調整が可能です。

### よくあるトラブルと解決チェックリスト
1.  **結合した際、ページ順序が逆になる・挟まる**
    *   原因：ドラッグ＆ドロップ時の誤操作でサムネイルの順序を逆に移動させたため。
    *   解決策：プレビューウィンドウ左側の「ページ」パネルから、番号を確認しながら正しい順序に配置し直してください。
2.  **分割時に画像がぼやける**
    *   原因：「印刷して保存」で解像度を下げた場合の副作用。
    *   解決策：標準機能での圧縮は画質劣化を伴うため、品質維持を優先する場合は「ファイル > エクスポート PDF...」を使用してください。
3.  **結合後のファイルサイズが膨大になる**
    *   原因：複数の高解像度スキャンPDFをそのまま結合した場合。
    *   解決策：macOS標準では高度な圧縮が難しいため、再出力時に「印刷 > PDF...」から品質を調整して保存します。

## 3. Linux（Ubuntu系）での実例手順

Linux環境ではGUIよりもコマンドラインツール（CLI）を組み合わせるのが最も確実でプロフェッショナルな方法です。

### 具体的な実例手順
標準のドキュメントビューア（Evince）には結合機能がないため、以下のパッケージを利用します。
*   **準備**: ターミナルを開き、必要なツールをインストールします。
    ```bash
    sudo apt update && sudo apt install poppler-utils pdftk
    ```
*   **結合**: `pdftk` または `pdfunite` を使用します。
    ```bash
    # pdftkを使用する場合
    pdftk file1.pdf file2.pdf cat output combined.pdf

    # pdfuniteを使用する場合
    pdfunite file1.pdf file2.pdf combined.pdf
    ```
*   **分割**: `pdftk` を使い、特定のページ範囲を指定して出力します。
    ```bash
    # 1〜5ページを抽出
    pdftk input.pdf cat 1-5 output part1.pdf
    ```
*   **圧縮**: 高度な最適化は難しいですが、`qpdf` を使ってWeb向けに線形化（Linearize）することで軽量化が可能です。
    ```bash
    qpdf --linearize combined.pdf output_optimized.pdf
    ```

### よくあるトラブルと解決チェックリスト
1.  **コマンド実行時「command not found: pdftk」とエラーが出る**
    *   原因：パッケージがインストールされていない。
    *   解決策：`sudo apt install poppler-utils pdftk` を再度実行してください。
2.  **結合後のPDFが開かない・文字化けする**
    *   原因：フォント埋め込みの不備やバージョンの不一致。
    *   解決策：`qpdf` で再エンコードを試みてください（例：`qpdf --linearize input.pdf output.pdf`）。
3.  **分割時にページ番号が指定できない**
    *   原因：引数の形式ミス（例：1-5と入力すべきところをカンマ区切りのみにするなど）。
    *   解決策：正確な範囲指定を確認してください。

## 4. iPad（iPadOS）での実例手順

iPadOSはモバイル端末であるため、PCに比べると標準機能の制約が多いですが、「ファイル」アプリと「ショートカット」を組み合わせることで対応可能です。

### 具体的な実例手順
*   **結合**: 「ファイル」アプリでPDFを選択し、長押ししてメニューから「コピー」を行い、新しいフォルダ等へ貼り付ける方法がありますが、バージョンによって挙動が不安定です。確実なのは「ショートカット」アプリです。
    *   **手順**: 「ショートカット」アプリを開き、「PDFファイルを作成」や「PDFを結合」というアクションを含むワークフローを作成（または公開されているテンプレートを利用）します。
*   **分割**: 「プレビュー」アプリでPDFを開きます。ページサムネイルを表示し、不要なページを選択して削除ボタンを押します。その後、そのまま保存することで分割されたファイルが得られます。
*   **圧縮**: iPadOS標準の「ファイル」アプリや「プレビュー」では、高度な圧縮機能は提供されていません。

---

## よくあるトラブルと解決チェックリスト

| トラブル内容 | 原因 | 解決策 |
| :--- | :--- | :--- |
| **結合後の文字化け** | フォントの埋め込み失敗 | 印刷設定で「高品質なグラフィックス」をオンにするか、PDF作成元のソフトでフォントを埋め込む。 |
| **ファイルサイズが減らない** | 画像圧縮アルゴリズムの不在 | Windows/macOS標準機能では限界があるため、どうしても必要な場合はWeb上の無料ツールや専用アプリを検討する。 |
| **ページ順序の誤り** | ドラッグ操作のミス | 結合前に必ず「プレビュー」または「印刷ダイアログ」で並び順を確認してから出力する。 |

## まとめ：快適なマルチOS環境を作るポイント

今回の比較でわかった通り、OSごとにPDFを扱うための「得意不得意」があります。Windowsは仮想プリンタでの対応、macOSは直感的なUI操作、Linuxは確実なコマンドライン操作、iPadはショートカットによる自動化という特徴を理解して使い分けるのがコツです。

より快適に事務作業を進めるためには、OSの標準機能に加え、以下の環境を整えることも検討してみてください。

*   **Office互換ソフト**: Google WorkspaceやMicrosoft 365を導入することで、PDF化する前の文書作成段階でレイアウトを正確に保つことができます。
*   **PDF編集ソフト**: 標準機能で限界を感じる場合は、Adobe Acrobatの代替として軽量な無料・安価なツール（例：PDF24など）を検討するのも手です。
*   **周辺機器**: 複数のOSを跨いで作業する場合、**外付けキーボード**や**大型モニター**は必須級のアイテムです。特にiPadとMacを併用するなら、同じキーボードで両方を操作できる環境を作ることで、PDFの結合・分割などの細かい微調整作業のストレスが劇的に軽減されます。

それぞれのOSの特性を活かした「自分に合ったワークフロー」を見つけ、効率的な事務作業を実現しましょう。
