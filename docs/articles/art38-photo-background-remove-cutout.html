写真の背景切り抜き・透過PNG作成を標準機能＆無料で行う実例｜Windows・macOS・iOS・Android

「SNSのアイコンを作りたいけれど、背景を透明にする方法がわからない」「Photoshopなどの高額なサブスクリプションを契約するほどではないけれど、手軽に背景を消したい」といった悩みをお持ちではありませんか？

画像制作において「背景の透過処理」は最も頻繁に発生する作業の一つです。しかし、OSによって標準機能の充実度は異なり、戸惑うことも多いでしょう。

この記事では、Adobe PhotoshopやCanvaなどの有料ツールを使わずに、各OS（Windows, macOS, iOS, Android）の標準アプリや公式の無料アプリを組み合わせて「背景を透過したPNG画像」を作成する具体的な手順を徹底解説します。

1. Windows 11 での実例手順

Windows環境では、標準の「フォト」アプリや「ペイント」で手動での切り抜きは可能ですが、AIによる自動背景除去機能は備わっていません。

標準機能での手順（手動）

  1. 「フォト」アプリまたは「ペイント」で画像を開きます。
  2. 編集モードに入り、選択ツール（「P」キーなど）を使用して被写体の周囲を囲みます。
  3. 境界線を微調整し、不要な部分を削除します。
  4. 「名前を付けて保存」を選択し、ファイル形式をPNGに指定して保存します。

省力化のための推奨アプローチ（AI活用）

標準機能での手動選択は毛並みや複雑な境界線の処理が難しいため、Microsoft Storeから公式の無料アプリ（例：PhotoRoom や Cutout.pro Clipper）をインストールして利用するのが最も効率的です。

注意点： 便利なツールとして知られる「PowerToys (Image Resizer)」は、画像のサイズ変更やフォーマット変換を行うためのものであり、背景の透過処理（AI切り抜き）機能は搭載していません。

よくあるトラブルと解決チェックリスト

  • 保存時に背景が白く残る
    • 原因：PNG形式を選択した際、ソフトの設定で「透明領域を白色で埋める」が有効になっているか、手動選択の境界線に余白が含まれている可能性があります。
    • 解決：「フォト」アプリの編集モードで境界線を厳密に調整し、保存時に透過設定を確認してください。
  • PowerToysを使っても透過にならない
    • 原因：PowerToys Image Resizerは「画像編集ソフト」ではなく「変換ツール」であるためです。
    • 解決：背景除去が必要な場合は、上記で紹介した専用の無料アプリへ切り替えてください。
  • 手動選択がうまくいかない（毛並みなど）
    • 原因：「フォト」アプリの自動境界線検出精度不足。
    • 解決：「P」キーで範囲を広めに選び、ツールバーの「削除」「追加」ボタンを使って細かく調整してください。

2. macOS での実例手順

macOSでは「プレビュー」アプリが強力ですが、ワンクリックでのAI背景除去は標準機能には含まれていません。

標準機能での手順（手動）

  1. 「プレビュー」アプリで画像を開きます。
  2. メニューの「表示」から「ツールバーを表示」を選択し、「選択範囲作成ツール」（矢印アイコン）をクリックします。
  3. 被写体を囲み、Commandキーを押しながら境界線を微調整します。
  4. 「ファイル」→「書き出し」から形式をPNGに指定して保存します。

自動化・AI活用の推奨アプローチ

  1. ショートカットアプリの活用: 標準搭載の「ショートカット」アプリに、Webサービス（PhotoRoom等）と連携するスクリプトを追加することで自動化が可能です。
  2. 専用アプリの利用: より高度な処理が必要な場合は、App Storeから公式の無料アプリ（PhotoRoom Mac版など）を導入するのがスムーズです。

注意点： Finderの「クイックアクション」にあるイメージ変換は、ファイル形式を変えるだけであり、背景を透明にする機能はありません。

よくあるトラブルと解決チェックリスト

  • プレビューで保存すると背景に白い枠ができる
    • 原因：PNGを選択した際に「透明ピクセルを白色で埋める」設定がオンになっているか、選択範囲外が含まれています。
    • 解決：「書き出し」ダイアログで設定項目を確認し、手動選択時に境界線を厳密に指定してください。
  • ショートカットスクリプトが動作しない
    • 原因：Webサービスとの連携権限不足やAPIキーの期限切れ。
    • 解決：ショートカットアプリ内で「Web」アクションの認証を再実行するか、専用アプリへ切り替えてください。
  • Finderクイックアクションで透過処理ができない
    • 原因：この機能はフォーマット変換（JPG→PNG等）のみに対応しています。
    • 解決：「書き出し」から手動選択を行うか、AIアプリを併用してください。

3. iOS（iPhone / iPad）での実例手順

iOSの「フォト」アプリには、現時点で背景をワンタップで透過させるボタンは標準搭載されていません。

標準機能とショートカットの連携

  1. 「フォト」または「ファイル」アプリで画像を開き、「共有」→「コピー」を選択します。
  2. 「ショートカット」アプリで、Webサービス（PhotoRoomなど）へ画像を送信し、結果をPNGで保存するワークフローを作成します。

推奨される代替案

iOSでは標準機能での手動切り抜きは精度が低いため、App Storeの公式無料アプリ（Cutout.pro Clipper for iOS や PhotoRoom Mobile）を使用するのが最も確実です。

よくあるトラブルと解決チェックリスト

  • ショートカットで保存した画像が透明でない
    • 原因：単なるフォーマット変換のみを行っており、AIによる背景除去プロセスを通っていないため。
    • 解決：ショートカット内にWebアクションを追加し、外部サービス経由で処理させるフローを確認してください。
  • 共有メニューからPNGが選べない
    • 原因：OSのバージョンや設定により、共有先としてPNGが表示されない場合があります。
    • 解決：「ファイル」アプリへ直接保存するか、専用アプリ内で出力形式を指定してください。
  • 写真の解像度が低すぎて切り抜き後ボヤける
    • 原因：標準のフォト編集ではピクセル単位の調整が粗いため。
    • 解決：高画質な元画像を使用するか、ショートカット経由の高精度Web処理を利用してください。

4. Android での実例手順

Androidの場合、メーカー（Samsung, Pixel等）によって標準ギャラリーの機能が大きく異なります。

標準機能での手順（機種による）

  1. 「ギャラリー」または「写真（Pixel）」アプリを開き、「編集」を選択します。
  2. ペンツールや選択範囲ツールで被写体を囲み、保存します。（※機種により名称が異なります）

AI/省力化の推奨アプローチ

Googleフォトアプリ内には背景除去機能は非搭載です。そのため、Google Playストアから公式無料アプリ（Cutout.pro Clipper for Android や PhotoRoom Mobile）をインストールして利用することを強く推奨します。

よくあるトラブルと解決チェックリスト

  • ギャラリーの保存時に背景が黒くなる
    • 原因：PNGを選択しても「透明領域を埋める」設定がないか、手動選択範囲に余白が含まれているため。
    • 解決：「編集」ツールで境界線を厳密にし、専用アプリへ移行して処理してください。
  • Google フォトの共有メニューに PNG がない
    • 原因：Googleフォトは透過を直接サポートしていない場合があります。
    • 解決：「編集」で手動選択後、PNGに変換するか、Playストアの無料アプリを使用してください。
  • 機種によるメニュー名の違い（Samsung vs Pixel など）
    • 原因：メーカーごとに「切り抜き」ツールの有無や名称が異なるため。
    • 解決：標準ギャラリーで対応していない場合は、Playストアの公式無料アプリを導入するのが最も安定した解決策です。

まとめ：快適なマルチOS環境を作るポイント

今回の比較で分かった通り、「OS標準機能だけで完璧なAI背景除去を行う」ことは現時点では難しいのが実情です。しかし、標準機能での手動切り抜きと、公式の無料アプリを組み合わせることで、高額なツールを使わなくても十分に高品質な透過PNGを作成することが可能です。

より快適でプロフェッショナルな制作環境を整えるためには、以下の周辺機器やツールの導入も検討してみると良いでしょう。

  • カラーマネジメントモニター: 正確な色再現は、切り抜き後の境界線の違和感を減らすために重要です。
  • ペンタブレット: マウスでは難しい細かい毛並みや複雑な形状の「手動切り抜き」を正確に行うことができます。
  • 外付けSSD: 高解像度の素材を扱う際、ストレージの速度は作業効率に直結します。
  • 画像編集ソフト（中級者向け）: 標準機能の限界を感じたら、まずは無料範囲の広いツールから段階的に導入を検討しましょう。

それぞれのデバイスの特性を理解し、最適なアプリと標準機能を使い分けることで、あなたのクリエイティブな作業はよりスムーズで快適なものになるはずです。
