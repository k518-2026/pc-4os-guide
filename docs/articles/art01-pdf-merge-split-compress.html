【4OS徹底比較】PDFの結合・分割・圧縮を無料で行う実例ガイド｜Windows・macOS・iOS・Android

「複数のPDFを1つにまとめたい」「長い資料から必要なページだけ抜き出したい」「メール添付のためにファイルサイズを軽くしたい」——。こうした場面で、有料ソフトを契約せずとも、OS標準機能や公式アプリだけで対応できる範囲はかなり広いです。

ただし、「標準機能だけでできること・できないこと」にはOSごとに明確な差があります。この記事では、初心者でも迷わない Windows 11・macOS・iOS（iPhone / iPad）・Android の4環境における正確な手順と、公式仕様に基づく制限事項・トラブル対処法を徹底比較します。

1. Windows 11 での実例手順

Windows 11 の標準機能（Microsoft Edge ＋ 仮想プリンタ Microsoft Print to PDF）で確実にできるのは「分割（必要ページの抽出）」です。

具体的な実例手順

  • 分割（特定ページだけ抽出）:
  • 対象のPDFファイルを Microsoft Edge で開く。
  • Ctrl + P で印刷ダイアログを開き、プリンターに 「Microsoft Print to PDF」（または「PDF として保存」）を選択。
  • 「ページ」欄をカスタムにし、抽出したいページ番号（例：1-3, 5）を指定して保存する。
  • 結合・圧縮について（標準機能の制限）:
  • Windows 標準の Microsoft Print to PDF 単体では複数PDFの結合や、画像再圧縮による大幅な軽量化は行えません。
  • 社外秘や個人情報を含むPDFを安全に無料結合・圧縮したい場合は、Web上の変換サイトにアップロードせず、PC上で完結するローカル無料ツール（例：PDF24 Creator や PDFsam Basic など）を併用するのが安心です。

2. macOS での実例手順

macOS は標準搭載の 「プレビュー（Preview）」 アプリが非常に強力で、結合・分割・圧縮の3つすべてが追加アプリなしで完結します。

具体的な実例手順

  • 結合:
  • 1つ目のPDFを「プレビュー」で開き、メニューバーから 「表示」＞「サムネイル」 を選択してサイドバーを表示する。
  • 結合したい別のPDFファイルを Finder からサイドバーの挿入したい位置へドラッグ＆ドロップする。
  • 「ファイル」＞「保存」（または「書き出す…」）で保存する。
  • 分割（不要ページの削除・抽出）:
  • サイドバーのサムネイルで不要なページを選択して Delete キーで削除するか、必要なページだけを選択してデスクトップ等へドラッグ＆ドロップすると、そのページだけの新しいPDFが作成されます。
  • 圧縮（ファイルサイズ削減）:
  • 「プレビュー」でPDFを開き、「ファイル」＞「書き出す…」 を選択（※「PDFとして書き出す」ではない点に注意）。
  • 「Quartz フィルタ」 のプルダウンから 「Reduce File Size」 を選択して保存する。

macOSでの注意点:
「Reduce File Size」は内蔵画像を強く再圧縮するため、細かい図表やスキャン文字が粗くなる場合があります。元ファイルは必ず別名保存で残してください。

3. iOS（iPhone / iPad）での実例手順

iOS でも、標準の 「ファイル」アプリ と 「ショートカット」アプリ を組み合わせることで、外部Webサービスにファイルをアップロードせずに結合・抽出が行えます。

具体的な実例手順

  • 結合（「ショートカット」アプリを使用）:
  • 「ショートカット」アプリを開き、新規ショートカットを作成。
  • アクションを追加：
    • 「ファイルを選択」（オプションで「複数を選択」をオン）
    • 「PDFを作成」（または複数画像・文書を1つのPDFにまとめるアクション）
    • 「ファイルを保存」
  • 実行して対象ファイルを選ぶだけで、結合済みPDFを「ファイル」アプリ内に保存できます。
  • 分割（特定ページの抽出）:
  • 「ファイル」アプリでPDFを開き、共有ボタン（上矢印）→ 「プリント」 をタップ。
  • 「範囲」で必要なページを指定し、プリント画面から共有ボタン → 「“ファイル”に保存」 を選ぶと、指定ページだけのPDFとして保存されます。
  • 圧縮:
  • iOS標準機能には画質調整付きの高度なPDF圧縮機能はありません。大幅な圧縮が必要な場合は、Macの「プレビュー」やPC側で処理するのが確実です。

4. Android での実例手順

Android では、標準搭載の Google Chrome や Google ドライブ の「印刷（PDFとして保存）」機能を使うと、追加アプリなしでページ抽出やスキャンPDF作成ができます。

具体的な実例手順

  • 分割（特定ページだけ抽出）:
  • PDFを Google ドライブ のPDFビューアまたは Chrome で開く。
  • 右上のメニュー（︙）→ 「印刷」 をタップ。
  • プリンター選択で 「PDF として保存」 を選び、「ページ」欄を「範囲」に変更して必要なページ番号（例：1-3, 5）を指定。
  • 保存ボタン（PDFアイコン）をタップして端末内やGoogleドライブに保存する。
  • 複数枚の紙資料を1つのPDFにまとめる（Google ドライブのスキャン機能）:
  • Google ドライブアプリ右下のカメラ（スキャン）アイコンから複数ページを連続撮影すると、自動的に1つの結合されたPDFとして保存されます。
  • 既存PDF同士の結合・圧縮:
  • Android標準機能単体では既存PDF同士の結合や高度な圧縮は非対応です。必要に応じてPC側で処理するか、信頼できる公式PDFアプリ（Adobe Acrobat Reader等）を併用してください。

まとめ：快適なマルチOS環境を作るポイント

PDFの結合・分割・圧縮は、「ページ抽出は4OSすべて標準で可能」「結合・圧縮まで標準で完結するのはmacOSが最強」という特徴があります。スマホとPCを併用している方は、重いPDFの結合・圧縮だけPC側で行うとスムーズです。

  • Office互換ソフト・PDF編集ソフト: 業務で頻繁にPDFのテキスト修正や墨消しを行う場合は、ローカル動作の専用PDFソフトを導入すると作業時間を大幅に短縮できます。
  • 外付けキーボード・大型モニター: 複数PDFを見比べながらページ順を整理する作業では、広い画面とショートカット操作が圧倒的に快適です。
