1. Windows 11 での実例手順

WindowsはPCとしての利便性が高い反面、Wi-Fiパスワードを「QRコードとして即座に表示する」というモバイル向けのUXは標準搭載されていません。そのため、以下のいずれかの手順をとるのが正解です。

公式仕様に基づく実例手順（PCでパスワードを確認）

  1. 「設定」アプリを開く。
  2. 左メニューの「ネットワークとインターネット」を選択し、上部の「Wi-Fi」をクリック。
  3. 現在接続中のネットワーク名をクリックし、画面下部の「プロパティ」へ移動。
  4. 「セキュリティ」セクション内の「表示パスワード」チェックボックスをオンにする（※PCのログインPINやパスワードによる認証が必要です）。
  5. 表示された文字列をメモ帳にコピーするか、来客に伝える。

Wi-Fiに接続させるための代替手段（QRコード表示）

  • 制限事項: Windowsの設定画面から直接QRコードを生成する機能はありません。
  • 解決策 A（推奨）: ルーター側から取得
    ブラウザでルーターの管理画面（ASUS, TP-Linkなど）にアクセスし、「ゲストネットワーク」設定や「QRコード表示」オプションを利用するのが最もスマートです。
  • 解決策 B: サードパーティ製アプリの活用
    Microsoft Store等で「Wi-Fi QR Code Generator」などの信頼できるツールを導入し、確認したパスワードを入力してQRコードを表示させます。

よくあるトラブルと解決法（Windows）

  1. 「表示パスワード」がグレーアウトしている: ユーザー権限不足です。管理者アカウントでログインするか、ルーターの管理画面から直接取得してください。
  2. パスワード入力しても接続できない: WPA3などの暗号方式がルーターとPCで不一致な場合があります。ルーター設定で「WPA2-AES」に固定すると互換性が向上します。

2. macOS での実例手順

macOSもiOSと同様、セキュリティを重視するため標準のQRコード生成機能は備わっていません。しかし、「キーチェーン」を活用することで確実にパスワードを特定できます。

公式仕様に基づく実例手順（キーチェーンから閲覧）

  1. 「システム設定」を開き、サイドバーの「ネットワーク」を選択。
  2. 接続済みのWi-Fiの横にある「詳細…」ボタンをクリック。
  3. 「Wi-Fiセキュリティ」のパスワード欄にカーソルを合わせ、Commandキー + クリック（または右クリック > コピー）で取得します。
    • ※最新OSでは「キーチェーンアクセス」アプリを開き、ネットワーク名で検索して「表示」アイコンをクリックする手順がより確実です。

Wi-Fiに接続させるための代替手段（QRコード表示）

  • 制限事項: macOS標準機能でのQR生成は不可です。
  • 解決策 A: Appleシステム間での共有
    同じiCloudアカウントのiPhoneであれば、設定画面から自動的に接続を促すことが可能です。
  • 解決策 B: サードパーティ製アプリの活用
    App Storeで「Wi-Fi Password Viewer & Generator」等のアプリを使用し、コピーしたパスワードからQRコードを作成します。

よくあるトラブルと解決法（macOS）

  1. キーチェーンでパスワードが表示されない: マスターパスワードの不一致や権限不足です。「システム設定 > Apple ID」からキーチェーンアクセスの権限を確認してください。
  2. 「詳細…」ボタンが灰色: 過去に接続したことがないネットワークです。ルーター管理画面から直接共有することをお勧めします。

3. iOS（iPhone / iPad）での実例手順

iOSは、近年のアップデートにより非常に便利な「ワンタップ共有」に近い体験が可能になっています。

公式仕様に基づく実例手順（パスワード閲覧とQR表示）

  1. 「設定」アプリを開き、「Wi-Fi」を選択。
  2. 接続中のネットワーク名の横にある「i (情報)」アイコンをタップ。
  3. 「パスワード」という項目をタップします。
  4. 最新のiOSでは、ここでQRコードが表示されます。（※OSバージョンや機種により挙動が異なる場合があります）
  5. そのQRコードを来客のiPhone/iPadのカメラで読み取ってもらうだけで接続完了です。

Wi-Fiに接続させるための代替手段（QRコード表示）

  • 解決策: ルーターメーカー公式アプリの活用
    iOS標準機能でQRが出ない場合や、より高度な制御をしたい場合は、「ASUS Router」や「TP-Link Tether」などの公式アプリを使用してください。ゲストネットワーク専用のQRコードを発行でき、メインネットワークのセキュリティを保ったまま共有できます。

よくあるトラブルと解決法（iOS）

  1. 「共有」ボタンが灰色で押せない: ネットワークが公共Wi-Fiや特定の制限がある場合です。ルーター管理画面から発行したQRコードを使用してください。
  2. 読み取っても反応しない: カメラのフォーカスが合っていないか、QRコードの有効期限（または距離）の問題です。少し離して再試行してください。

4. Android での実例手順

Androidは、OS標準機能として最も「QRコード共有」に優れたUXを提供しています。

公式仕様に基づく実例手順（パスワード閲覧と接続）

  1. 「設定」アプリを開き、「ネットワークとインターネット」 ＞ 「インターネット」を選択。
  2. 現在接続中のWi-Fiの横にある「歯車アイコン（設定）」をタップ。
  3. 画面下部にある「QRコード」ボタンをタップします。
  4. 生成されたQRコードを来客に見せるだけで、相手のAndroid端末はカメラをかざすだけで自動的に接続情報を取得します。

Wi-Fiに接続させるための代替手段（QRコード表示）

  • 解決策: ルーター管理画面からのQRコード
    Android標準機能でQRが出ない古い機種やカスタムROMの場合、ルーターメーカーの公式アプリからゲストネットワーク用QRコードを取得するのが最も確実です。

よくあるトラブルと解決法（Android）

  1. QRコードが表示されない: Androidのバージョンやメーカー独自のカスタマイズによりメニューが異なる場合があります。その場合は「設定 > Wi-Fi」からパスワード文字列を直接確認してください。
  2. 読み取り後に自動接続されない: 相手の端末で「Wi-Fiを許可する」などのポップアップが出ている場合があります。画面上の指示に従ってタップを促してください。

まとめ：快適なマルチOS環境を作るポイント

自宅のWi-Fi共有をスムーズにするためには、各OSの特性を理解した上で「どの手段を使うか」を決めるのが近道です。

  • iPhone/Androidユーザーなら: 設定画面からQRコードを表示させるのが最もスマートで安全です。
  • PC（Windows/Mac）ユーザーなら: 標準機能でのQR生成に頼らず、ルーターの管理画面を使いこなすことが「プロ」のやり方です。

また、より快適なネットワーク環境を構築するために、以下の周辺機器の導入も検討してみてください。

  • Wi-Fi 6/6E/7ルーター: 最新規格に対応することで、多数のデバイスが同時接続しても速度低下を防ぎます。
  • 家庭用NAS: Wi-Fiパスワードを共有するだけでなく、家族や友人と安全にファイルを共有したいなら必須のアイテムです。
  • LANケーブル & スイッチングハブ: 安定性が求められるPCやゲーム機は有線接続が基本。ルーターからスイッチングハブへ繋ぎ、各デバイスへ配線することで、Wi-Fiの混雑を回避できます。

これらのツールと正しい共有手順を組み合わせることで、セキュリティと利便性を両立した「ストレスフリーな自宅ネットワーク」を実現しましょう。
