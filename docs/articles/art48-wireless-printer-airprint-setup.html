Wi-Fiプリンターへのワイヤレス印刷設定と「オフライン」エラー解決実例｜Windows・macOS・iOS・Android

「Wi-Fiプリンターを買ったのに、スマホやPCからうまく印刷できない」「急に『オフライン』と表示されて動かなくなった」といったトラブルは、マルチデバイス環境で非常に多く遭遇する悩みです。

実は、OSごとにワイヤレス印刷の仕組み（プロトコル）や設定手順が異なるため、共通の操作だけでは解決しないケースが多々あります。この記事では、Windows、macOS、iOS、Androidの4つの主要OSにおいて、ワイヤレスプリンターを正しく認識させる手順と、最も多い「オフライン」エラーの具体的な解決策を徹底解説します。

1. Windows 11 での実例手順

Windowsでは、プリンターメーカーが提供する「ドライバ」が正しくインストールされているかどうかが鍵となります。

設定と接続の手順

  1. 基本設定: 「スタート」＞「設定（歯車アイコン）」＞「Bluetooth とデバイス」＞「プリンターとスキャナー」を開きます。
  2. 追加方法: 「デバイスの追加」をクリックし、ネットワーク上のプリンターを自動検索させます。
  3. IPアドレスでの直接指定（推奨）: 自動で検出されない場合や接続が不安定な場合は、「プリンターの追加」画面の「プリンターが一覧にありません」を選択し、「TCP/IP アドレスまたはホスト名を使用してプリンターを追加する」から、プリンター本体のIPアドレスを直接入力します。
  4. 印刷時の選択: 任意のアプリ（Wordやブラウザ等）で Ctrl + P を押し、適切なドライバ（HP Smart, Canon IJ Printer Utilityなど）を選択して実行します。

標準機能の制限事項

Windows 11には、iOS/macOSのような「AirPrint」ボタンのような汎用的なワンタッチ選択ボタンは標準では存在しません。基本的にはメーカー提供のドライバを正しくインストールし、適切なポート（TCP/IP等）を割り当てる必要があります。

よくあるトラブルと解決法

  • 「オフライン使用中」表示の直し方: 「プリンターとスキャナー」から対象のプリンターを選択し、「管理」＞「プリンターをオンラインにする」をクリックします。※物理的な電源やWi-Fiが切断されている場合は無効です。
  • IP アドレス変更による接続失敗: ルーター再起動等でプリンターのIPが変わると通信不能になります。「ポートの追加」から最新のIPアドレスに更新してください。
  • ドライバーの不整合エラー: 「詳細設定」からの更新ではなく、メーカー公式サイトから最新のインストーラーをダウンロードして再インストールすることを強く推奨します。

2. macOS での実例手順

macOSは「AirPrint」という強力な標準規格があるため、多くの場合で非常にスムーズに接続できます。

設定と接続の手順

  1. ネットワーク確認: 「システム設定」にてWi-Fiがオンになっていることを確認します。
  2. 自動認識: 印刷ダイアログ（Command + P）を開いた際、AirPrint対応プリンターであれば自動的にリストに表示されます。
  3. 手動追加: リストに出ない場合は「システム設定」＞「プリンターとスキャナー」から「プリンター、スキャナ、またはファックスを追加」を選択。
  4. IP指定: 接続方法として「IP プリンタを追加」を選び、TCP/IPを指定してAirPrintプロトコルを選択します。

標準機能の制限事項

非AirPrint対応の古いWi-Fiプリンターは、自動発見（共有とiCloud経由）が行われないことがあります。また、Bluetooth接続のみでは印刷は不可能です（Bluetoothはアクセサリ用であり、印刷にはWi-Fiネットワークを介した通信が必要です）。

よくあるトラブルと解決法

  • 「オフライン」と表示される場合: プリンター本体のWi-Fiアイコンが点滅していないか確認。システム設定のネットワーク項目からWi-FiのIPアドレスをリフレッシュ（再取得）させてください。
  • AirPrint が認識されないエラー: ルーターおよびプリンターのファームウェア更新が必要です。古いプロトコルが非対応な場合は「IPP プリンタを追加」として手動指定してください。
  • 印刷ジョブの消失: バックグラウンドプロセス（macOS版Print Spooler）の不具合の場合があります。「共有」＞「オプション」でプリントキューの状態を確認してください。

3. iOS（iPhone / iPad）での実例手順

iOSは最もシンプルですが、ネットワーク環境に敏感な仕様となっています。

設定と接続の手順

  1. 標準機能: 「コントロールセンター」＞「印刷」をタップし、同一Wi-Fi内のプリンターを選択します。
  2. メーカーアプリの活用: AirPrint非対応機種の場合、Apple Storeから「HP Smart」「Canon PRINT」などの公式アプリをインストールして使用します。

標準機能の制限事項

iOSの設定画面内に「Bluetoothでプリンターを接続する」という項目はありません。iPhoneとプリンターをBluetoothでペアリングしても印刷はできません。純正AirPrintはWi-Fi経由のみとなります。

よくあるトラブルと解決法

  • 「オフライン」と表示される場合: iPhoneとプリンターが同じSSID（ネットワーク名）に接続されているか再確認してください。「設定」＞「Wi-Fi」で一度切断し、再接続することでセッションをリセットできます。
  • 印刷ダイアログにプリンターが出ないエラー: iOSのバージョンアップにより古いAirPrintプロトコルが遮断されることがあります。この場合はメーカー製アプリの導入を検討してください。
  • 印刷中に表示が消える問題: 通信瞬断が原因であることが多いため、再度コントロールセンターからメニューを開き直すことで解決することが多いです。

4. Android での実例手順

Androidは機種やメーカーによってUIが異なりますが、Google Cloud Print廃止以降、アプリの活用が主流です。

設定と接続の手順

  1. 標準設定: 「設定」＞「デバイス」＞「プリンター」からWi-Fi上のプリンターを検出します（機種依存あり）。
  2. メーカー製アプリ: ほとんどのケースで「Samsung SmartThings Printer」「HP Smart」などの公式アプリを使用するのが最も確実です。

標準機能の制限事項

AndroidでもBluetoothでのペアリングは印刷には利用できません。また、PixelやGalaxyなどメーカーによって標準搭載されているプリインストールアプリの名称や機能が異なるため注意が必要です。

よくあるトラブルと解決法

  • 「オフライン」と表示される場合: プリンター本体のWi-Fiインジケーターを確認。Android側の「設定」＞「ネットワークとインターネット」からWi-Fiを再取得させてください。
  • 印刷ダイアログにプリンターが出ないエラー: ルーターおよびデバイスのファームウェア更新が必要です。古いプロトコルが非対応な場合はメーカーアプリへの切り替えを推奨します。
  • 印刷中に表示が消える問題: クイックパネル（コントロールセンター）から再度メニューを開き直すか、ネットワーク設定を一度オフにして再接続してください。

よくあるトラブルと解決チェックリスト

ワイヤレス印刷で「動かない」と感じたときは、以下の項目を上から順に確認してください。

  • [ ] 【物理層】 プリンターの電源は入っているか？ Wi-Fiランプは点灯（または常時点滅）しているか？
  • [ ] 【ネットワーク層】 PC/スマホとプリンターは「同じWi-Fi（SSID）」に接続されているか？（※ゲストWi-Fiや5GHz/2.4GHzの分離設定に注意）
  • [ ] 【IPアドレス】 プリンターのIPアドレスが変わっていないか？（ルーター再起動後に変わることが多いです。固定IPの設定を推奨）
  • [ ] 【ドライバ・アプリ】 Windowsなら最新ドライバ、iOS/Androidならメーカー公式アプリが最新バージョンか？

まとめ：快適なマルチOS環境を作るポイント

Windows、macOS、iOS、Androidのどれを使っても、ワイヤレス印刷における共通の鉄則は「デバイスとプリンターを同じネットワーク内に正しく配置すること」です。特に「オフライン」エラーの多くは、IPアドレスの変動やネットワークの分離（セグメント分け）によって発生します。

また、より安定したマルチOS環境を構築するためには、周辺機器の選び方も重要です。
例えば、複数のデバイスをスムーズに切り替えるためのUSB-Cドッキングステーションや、PCとMacを交互に使う際のKVM切替器、そして全てのデバイスで共通して使えるマルチペアリングキーボード・マウスを導入することで、OS間の移動によるストレスを最小限に抑え、快適なワークスペースを実現できます。

まずは現在の接続状態（IPアドレス）を正確に把握することから始めてみてください。
