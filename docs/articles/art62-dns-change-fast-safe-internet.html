サイトが開けない・遅い時のDNS設定（1.1.1.1 / 8.8.8.8）変更実例｜Windows・macOS・iOS・Android

「特定のWebサイトだけがどうしても開かない」「検索結果がいつもと違う気がする」「動画の読み込みが極端に遅い」……。そんなトラブルに直面した際、意外な落とし穴となっているのがDNS（Domain Name System）の設定です。

インターネット上の住所（IPアドレス）を名前（URL）に変換する「電話帳」の役割を果たすDNSサーバーですが、プロバイダー（ISP）が提供する標準のDNSサーバーは、時として混雑や不具合でレスポンスが低下することがあります。

この記事では、世界的に信頼性の高い公共DNSであるCloudflare（1.1.1.1）やGoogle（8.8.8.8）へ設定を変更し、ネットワークの安定性を向上させるための具体的な手順を、Windows、macOS、iOS、Androidの4つの主要OSごとに徹底解説します。

1. Windows 11 での実例手順

Windowsでは、ネットワークアダプタのプロパティから直接指定する方法が最も確実です。

公式仕様に基づく正確な実例手順

【GUI メソッド（推奨）】
1. Windows キー + I を押し、「設定」を開きます。
2. 「ネットワークとインターネット」を選択し、現在接続中の「Wi-Fi」または「イーサネット」をクリックします。
3. 画面上部の「プロパティ」ボタンを押します。
4. 「DNSサーバー割り当て」の横にある「編集」ボタンをクリックします。
5. 「自動 (DHCP)」から「手動」に変更し、IPv4をオンにします。
6. 優先 DNS: 1.1.1.1 / 代替 DNS: 8.8.8.8 を入力して保存します。

【コマンドラインメソッド（管理者権限）】
※接続名（例: "Wi-Fi"）は環境に合わせて変更してください。

netsh interface ip set dns "Wi-Fi" static 1.1.1.1
netsh interface ip add dns "Wi-Fi" 8.8.8.8 index=2

標準機能の制限事項・非対応項目

  • IPv6 の同時設定: GUIでは可能ですが、netshコマンドで両方を一括で設定する簡易なワンライナーは存在しません。
  • 動的 IP 環境での永続化: ルーターのDHCPサーバーが強力にDNSを上書きする場合、PC側の設定変更だけでは効果が持続しないことがあります。

よくあるトラブルと解決法（Windows）

  1. 「DNS サーバーアドレス」を入力しても反映されない
    • 原因: IPv4プロトコルが選択されていないか、DHCP経由の取得が強制されている。
    • 解決: 「使用可能な DNS サーバーアドレスの指定」にチェックが入っているか確認し、再起動してください。
  2. 「ipconfig /flushdns」としても直らない
    • 原因: OSのキャッシュではなく、ルーター側のDHCPスコープが古いDNSを配信している。
    • 解決: ルーターの設定画面から「DHCPサーバー」→「DNSアドレス設定」で 1.1.1.1 に変更するのが最も根本的な解決策です。
  3. 「特定サイトは開けるが、検索結果だけが違う」
    • 原因: DNSポイズニングやキャッシュの不一致。
    • 解決: 一度「自動」に戻して ipconfig /flushdns を実行し、ブラウザを再起動してください。

2. macOS での実例手順

macOSは直感的なGUIで設定が可能ですが、ルーターとの兼ね合いに注意が必要です。

公式仕様に基づく正確な実例手順

【GUI メソッド（推奨）】
1. Appleマーク ＞ 「システム設定」＞「ネットワーク」を開きます。
2. 使用中の「Wi-Fi」または「Ethernet」を選択し、「詳細...」ボタンを押します。
3. 左側のメニューから「DNS」タブを選択します。
4. 「DNSサーバー」欄の「＋」ボタンを押し、1.1.1.1 と 8.8.8.8 を追加します。
5. 「適用」をクリックします。

【コマンドラインメソッド】

sudo networksetup -setdnsservers "Wi-Fi" 8.8.8.8 1.1.1.1

標準機能の制限事項・非対応項目

  • IPv6 の優先順位制御: GUIで同時に設定できても、OSがどちらを優先するかは手動指定できません。
  • Secure DNS (DoH) との違い: 本手順は「DNSレゾルバー」の変更です。Safari等の「プライバシーとセキュリティ」にある「Secure DNS」とは別機能であることに注意してください。

よくあるトラブルと解決法（macOS）

  1. 「詳細...」ボタンがグレーアウトしている
    • 原因: ネットワークアダプタが無効、またはシステム拡張権限不足。
    • 解決: 「ネットワーク」画面で該当接続を一度オフにしてから再度オンにし、設定を試みてください。
  2. 「DNS サーバーフィールド」に入力しても保存されない
    • 原因: サードパーティ製ファイアウォール（Little Snitch等）の干渉。
    • 解決: セキュリティソフトを一時停止し、再度設定してください。改善しない場合はネットワーク接続を一度削除して再作成します。
  3. 「Wi-Fi を切替ると DNS が元に戻る」
    • 原因: ルーターのDHCPサーバーが常にISPのアドレスを配信しているため。
    • 解決: ルーター側の「DHCP」設定からDNSを固定値に変更するか、PC側で「自動」ではなく「手動」を維持する必要があります。

3. iOS（iPhone / iPad）での実例手順

iOSではWi-Fiネットワークごとに個別の設定を行う形になります。

公式仕様に基づく正確な実例手順

【GUI メソッド（推奨）】
1. 「設定」アプリ ＞「Wi-Fi」を開きます。
2. 接続中のネットワーク名の右側にある「i」マークをタップします。
3. 「DNS」を選択し、「自動」から「手動」に変更します。
4. リストにある既存のアドレスを削除（または編集）し、1.1.1.1 を追加します。

標準機能の制限事項・非対応項目

  • ルーター全体への適用不可: iPhoneの設定変更は、その端末のみが対象です。家庭内の他の機器には影響しません。
  • IPv6 の同時指定: iOSのDNS設定画面では基本的にIPv4アドレスしか入力できません。

よくあるトラブルと解決法（iOS）

  1. 「DNS」メニューが表示されない
    • 原因: Wi-Fiに接続されていない、または特定のVPN/プロキシ環境下にある。
    • 解決: 一度Wi-Fiをオフにし、再接続してから「i」マークを確認してください。
  2. 「DNS サーバーを追加」しても入力できない
    • 原因: iOSのUI不具合やロック状態。
    • 解決: iPhoneを再起動し、再度設定を行ってください。
  3. 「サイトは開けるが検索結果が違う」
    • 原因: Safariのキャッシュやアプリ内ブラウザの影響。
    • 解決: Safariの「共有」ボタンから「コンテンツを消去」を実行してください。

4. Android での実例手順

Androidは機種（Pixel, Galaxy等）によりUIが異なりますが、基本構造は共通しています。

公式仕様に基づく正確な実例手順

【GUI メソッド（推奨）】
1. 「設定」アプリ ＞「ネットワークとインターネット」＞「Wi-Fi」を開きます。
2. 接続中のネットワーク名の横の歯車アイコンをタップします。
3. 「IP設定」または「DNS」項目を選択し、「静的（Static）」に変更します。
4. DNSサーバー欄に 1.1.1.1 を入力します。

標準機能の制限事項・非対応項目

  • IPv6 の同時指定: 多くの機種では、DNSフィールドにはIPv4のみ入力可能です。
  • 「静的 IP」と「動的 IP」の混在不可: 「静的IP」を選択するとサブネットマスクやゲートウェイも入力が必要になります。これらを正しく設定できない場合は、標準機能のみでは「DNS変更のみ」に留めるのが難しい場合があります。

よくあるトラブルと解決法（Android）

  1. 「静的 IP」を選択すると他の項目も入力が必要になるが、保存できない
    • 原因: サブネットマスクやゲートウェイを正しく入力していない。
    • 解決: 家庭用ルーター環境ではこれらを省略してDNSだけ変えることが難しいため、ルーター側の設定でDNSを変更するのが最もスムーズです。
  2. 「プライベートDNS」機能との競合
    • 原因: Androidの「プライベートDNS（DoT）」が有効になっていると、Wi-Fi個別のDNS設定が無視されることがあります。
    • 解決: 「設定」＞「ネットワークとインターネット」＞「プライベートDNS」をオフにするか、そこで直接 1.1.1.1 を指定してください。

よくあるトラブルと解決チェックリスト

トラブル現象 原因の可能性 対処法
設定変更後、反映されない OSやブラウザに古いキャッシュが残っている ipconfig /flushdns (Win) やブラウザのキャッシュクリアを実行。
特定のサイトだけ開かない DNSサーバー側の障害、またはISPの制限 別の公共DNS（8.8.8.8など）へ切り替えて確認。
設定が勝手に「自動」に戻る ルーターのDHCPサーバーが上書きしている PC/スマホ側ではなく、ルーター自体のDNS設定を変更する。
速度が変わらない DNS以外の要因（回線混雑・Wi-Fi干渉） Wi-Fi 6対応ルーターやLANケーブルの規格を確認する。

まとめ：快適なマルチOS環境を作るポイント

DNSの設定変更は、Webブラウジングの「第一歩」をスムーズにするための非常に有効な手段です。しかし、これだけで全てのネットワークトラブルが解決するわけではありません。

より快適で安定したマルチOS環境（Windows, Mac, iPhone, Android）を構築するためには、以下のインフラ整備も併せて検討することをお勧めします。

  • Wi-Fi 6/6E/7ルーター: DNSの応答速度だけでなく、デバイスの同時接続数や通信の安定性を劇的に向上させます。
  • 家庭用NAS: ネットワーク内のファイル共有（SMB）を高速化し、OS間のデータ連携をスムーズにします。
  • LANケーブル & スイッチングハブ: PCやゲーム機など、安定性が求められるデバイスには有線接続が必須です。Cat6A以上の規格のケーブルと、ギガビット対応のスイッチングハブを導入することで、DNS設定の恩恵を最大限に引き出せます。

まずは今回紹介した「1.1.1.1 / 8.8.8.8」への変更から始めて、ストレスのないインターネット環境を手に入れましょう。
